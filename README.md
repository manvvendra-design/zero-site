# Zero

The website for **Zero**, live comics from the Dibang Valley: zerosnaketree.com.

A plain static site, no build step. Hosted on Cloudflare Pages: every push to `main` goes live.

- `index.html`: the page. New frames go in the `FRAMES` list near the bottom, once approved.
- `assets/`: frame images (WebP), the Zero logo, the share image.
